# YOMUの計算ロジックを全部公開します

> この記事は **2026年9月時点の計算仕様** です。計算方法を変えたら記事も書き換え、末尾の更新履歴に残します。

YOMUは物件1件につき、同じ入力から **保守シナリオ** と **楽観シナリオ** の2本を計算し、その差を金額で出します。この記事は、その計算で「どの数字に何を掛け、何を引いているか」を省略せずに書いたものです。

2,000万円を超える判断に使う数字を、中身の見えない箱から出すわけにはいきません。前提が自分の物件に合わないと思ったら、それが分かるように書きました。都合の悪い簡略化も、最後の「[YOMUが計算していないこと](#limits)」にまとめています。

なお、計算式はFreeでもProでも同じです。プランで変わるのは使える画面だけです。

---

## 1. 計算の全体像 {#flow}

保有期間（初期値35年）を1年ずつ進め、各年を12ヶ月に分けて順に計算します。35年なら420ヶ月です。

ただし、すべてが月ごとに変わるわけではありません。**入居・退去とお金の出入りは月単位、金利や家賃の「水準」は年単位**で動かしています。

| タイミング | 計算すること |
|---|---|
| 毎年のはじめ | その年の金利・家賃・建物管理費・経常修繕費の水準を決める。元利均等なら毎月返済額を計算し直す |
| 毎月 | ① 入居・退去の判定 → ② 入居中なら家賃・管理委託料・更新料 → ③ 建物管理費・固定資産税等・保険・経常修繕費 → ④ ローンの利息と元金 |
| 毎年のおわり | 設備交換・大規模修繕 → 減価償却と税 → 単年キャッシュフロー |
| 保有期間の最後 | 売却 → 総合損益 → IRR |

金利は年に1回、年のはじめに改定します。月の途中で金利が変わるモデルではありません。

## 2. この記事の計算例：サンプル物件 {#sample}

以下の数字はすべて、アプリのホームにある **サンプル物件（1R・2,480万円）** をそのまま計算した結果です。アプリで同じ物件を開けば、同じ数字が出ます。

| 区分 | 前提 |
|---|---|
| 物件 | 価格 2,480万円 ／ 購入諸費用 7% ／ 建物割合 45% ／ 残存償却年数 37年 |
| 家賃 | 月92,000円 ／ 下落率 年0.7% ／ 更新 2年ごと・貸主受取0.5ヶ月分 ／ 礼金 0ヶ月 |
| 入退去 | 平均入居 5年 ／ 退去後の空室 1.5ヶ月 ／ 原状回復費 120,000円/退去 ／ 募集広告料 0.5ヶ月分 |
| 融資 | 自己資金 100万円 ／ 35年・元利均等 ／ 当初金利 0.8% ／ 上昇 年+0.02pt ／ 上限 3.0% |
| 経費 | 管理委託料 家賃の4% ／ 建物管理費・修繕積立金 月10,000円（年+0.7%）／ 固定資産税等 年55,000円 ／ 保険 年12,000円 |
| 修繕 | 経常修繕費 年20,000円（年+1.5%）／ エアコン 15年ごと12万円 ／ 給湯器 12年ごと18万円 ／ ガスコンロ 15年ごと6万円 ／ 大規模修繕 なし |
| 税 | 計算しない（税引前）。オンにした場合の例は限界税率30%・損益通算あり |
| 売却 | 35年目に売却 ／ 価格変動方式 年+0.5% ／ 売却諸費用 4% ／ 譲渡税を考慮 |

計算は円未満を含めて行っているため、表示した数字を足し引きすると1円ずれることがあります。

## 3. ローン {#loan}

### 借入額

```formula
借入額 = 物件価格 − 自己資金
```

購入諸費用は借入に含めず、現金で払う前提です。サンプルでは借入2,380万円、現金で払う諸費用は173.6万円です。

### 金利

```formula
その年の金利 = min( 当初金利 + 年あたり上昇幅 × (経過年数 − 1) , 金利上限 )
```

サンプルでは1年目0.80%、2年目0.82%、10年目0.98%、20年目1.18%、35年目1.48%です（上限3.0%には届きません）。

### 毎月の返済

**元利均等** では、毎年のはじめに「その時点の残債・残り回数・その年の金利」で毎月返済額を計算し直します。

```formula
月利       = 年利 ÷ 12
毎月返済額 = 残債 × 月利 ÷ ( 1 − (1 + 月利)^(−残り回数) )
その月の利息 = 残債 × 月利
その月の元金 = 毎月返済額 − その月の利息
```

**元金均等** では、元金は毎月「当初借入額 ÷ 総回数」で一定、利息は同じく「残債 × 月利」です。

サンプルの1年目は、毎月返済額64,989円。最初の月の利息は15,867円、元金は49,122円です。1年間の返済合計は779,862円（うち利息188,234円）になります。

実際の変動金利ローンによくある「返済額の見直しは5年ごと」「見直し後の返済額は従来の1.25倍まで」というルールは再現していません。YOMUは金利が上がった年から返済額そのものを引き上げるので、金利上昇局面の途中年のキャッシュフローは厳しめに出ます。

## 4. 家賃と入居・退去 {#rent-vacancy}

### 家賃

```formula
その年の月額家賃 = 当初家賃 × (1 − 家賃下落率)^(経過年数 − 1)
```

サンプルでは2年目91,356円、10年目86,364円、20年目80,505円、35年目72,454円です。

保守シナリオでは、**入居中の人の家賃も毎年下げます**。現実には入れ替えや更新のときにしか下がらないことが多いので、ここは保守側に倒した簡略化です。

### 入居・退去のサイクル

保守シナリオでは、次のサイクルを保有期間の最後まで機械的に繰り返します。

1. 購入時点で入居者がいる状態から始める
2. 平均入居期間が過ぎた翌月に退去。その月に **原状回復費** を経費に計上
3. 空室期間は家賃ゼロ。建物管理費・税・保険・ローン返済は止まらない
4. 次の入居者が入った月に、**募集広告料**（家賃×ADヶ月数）を経費、**礼金**（家賃×礼金ヶ月数）を収入に計上
5. 入居中の月だけ、家賃と **管理委託料**（家賃×委託料率）を計上
6. 同じ入居者の入居月数が「更新周期×12」の倍数に達した月に、**更新料**（家賃×貸主受取ヶ月数）を収入に計上

入居期間と空室期間は月単位に四捨五入します。サンプルの空室1.5ヶ月は2ヶ月として計算されます。退去の時期は毎回「平均」どおりで、早まったり遅れたりするばらつきは入れていません。その影響は[感度分析](#analysis)で入居期間±1年、空室±1ヶ月を振って確認します。

### 例：サンプル物件の6年目

5年間住んだ最初の入居者が6年目の1月に退去し、2ヶ月の空室を経て3月に次の入居者が入ります。

| 項目 | 金額 |
|---|---:|
| 家賃収入（88,825円×10ヶ月） | 888,248円 |
| 原状回復費 | −120,000円 |
| 募集広告料（0.5ヶ月分） | −44,412円 |
| 管理委託料（収入の4%） | −35,530円 |
| 建物管理費・修繕積立金 | −124,259円 |
| 固定資産税等・保険 | −67,000円 |
| 経常修繕費 | −21,546円 |
| ローン返済 | −791,892円 |
| **単年キャッシュフロー** | **−316,391円** |

1年目に+72,978円だったキャッシュフローが、退去が1回あるだけでこうなります。

## 5. 運営経費 {#expenses}

| 項目 | 計上のしかた | 保守 | 楽観 |
|---|---|---|---|
| 管理委託料 | 入居中の月だけ、家賃×委託料率 | ○ | ○（常に満室） |
| 建物管理費・修繕積立金 | 毎月。毎年、増額率で複利増額 | 増額あり | 当初額のまま |
| 固定資産税等・保険・その他 | 年額÷12を毎月。増額なし | ○ | ○ |
| 経常修繕費 | 年額÷12を毎月。毎年、上昇率で複利増額 | 上昇あり | 当初額のまま |
| 設備交換 | 周期の倍数の年に全額（給湯器12年ごと→12年目・24年目） | ○ | 計上しない |
| 大規模修繕 | 周期の倍数の年に全額 | ○ | 計上しない |
| 原状回復費・募集広告料 | 退去・入居のたび | ○ | 計上しない |

設備交換の周期は **購入1年目から数えます**。設備台帳に入れた設置年は、この収支計算には使っていません。設備交換・大規模修繕・原状回復費・募集広告料・固定資産税等には物価上昇を掛けていません。

## 6. 減価償却と税 {#tax}

税は「不動産所得への課税を考慮する」をオンにしたときだけ計算します。**初期設定はオフで、表示されるキャッシュフローは税引前です。**

### 減価償却費

```formula
年間の減価償却費 = 物件価格 × 建物割合 ÷ 残存償却年数
```

定額で、残存償却年数を過ぎた年から0になります。サンプルは2,480万円×45%÷37年＝年301,622円です。

### 税額

```formula
課税所得 = 収入 − 運営経費（設備交換・大規模修繕を含む） − ローン利息 − 減価償却費
税額     = 課税所得 × 限界税率（所得税＋住民税）
```

ローンの元金は経費にならないので引きません。**損益通算あり** の場合、課税所得がマイナスなら「マイナス×税率」を還付（給与などの税が減る分）としてキャッシュフローに足します。**損益通算なし** の場合、マイナスの年の税は0です。

サンプルを限界税率30%で計算すると、1年目の課税所得は362,985円、税額は108,895円です。税引前で+72,978円だった1年目のキャッシュフローは、税引後では **−35,917円** になります。

### デッドクロス

ローンの元金返済（お金は出ていくのに経費にならない）が、減価償却費（経費になるのにお金は出ていかない）を上回る状態をデッドクロスと呼びます。YOMUでは、償却が切れた年から課税所得が一段上がり、年次明細の「税」の列が跳ねる形で表れます。

サンプル物件は1年目から元金591,628円が償却費301,622円を上回っていますが、残存償却年数37年が保有期間35年より長いため、償却切れによる税の跳ね上がりは期間内に起きません。

## 7. キャッシュフロー {#cashflow}

```formula
単年キャッシュフロー = 収入 − 運営経費 − ローン返済（元金＋利息） − 税
累積キャッシュフロー = 単年キャッシュフローの合計
```

サンプルの保守シナリオでは、1年目は+72,978円（月あたり約6,081円）、初めて単年で赤字になるのは6年目、35年間の累積は **−5,395,484円** です。

## 8. 売却と総合損益 {#exit}

### 売却価格

2つの方式から選べます。

```formula
利回り方式   売却価格 = 売却する年の月額家賃 × 12 ÷ 売却時の表面利回り
価格変動方式 売却価格 = 物件価格 × (1 + 年あたり変動率)^保有年数
```

利回り方式の家賃は、売却する年の満室時の家賃です。

### 売却手取りと総合損益

```formula
売却諸費用   = 売却価格 × 売却諸費用率
簿価         = 物件価格 − 減価償却費の累計
譲渡税       = max( 0 , 売却価格 − 売却諸費用 − 簿価 ) × 20.315%
売却手取り   = 売却価格 − 売却諸費用 − 売却時の残債 − 譲渡税
初期自己資金 = 自己資金 + 物件価格 × 購入諸費用率
総合損益     = 累積キャッシュフロー + 売却手取り − 初期自己資金
```

### 例：サンプル物件を35年目に売却

| 項目 | 金額 |
|---|---:|
| 売却価格（2,480万円×1.005^35） | 29,530,027円 |
| 売却諸費用（4%） | −1,181,201円 |
| 簿価（2,480万円 − 償却累計10,556,757円） | 14,243,243円 |
| 譲渡税（譲渡益14,105,583円×20.315%） | −2,865,549円 |
| 残債 | 0円 |
| **売却手取り** | **25,483,277円** |
| 累積キャッシュフロー | −5,395,484円 |
| 初期自己資金（100万円＋諸費用173.6万円） | −2,736,000円 |
| **総合損益** | **+17,351,793円** |

家賃収入だけでは540万円のマイナスで、総合損益のプラスは売却でつくられています。つまりこの物件の結論は、売却の前提ひとつで大きく変わります。

同じ物件を利回り方式・売却時利回り6%で計算すると、売却価格は72,454円×12÷6%＝約1,449万円になり、総合損益は約+578万円まで下がります。売却の前提は、必ず両方の方式で確かめてください。

## 9. 投資指標：IRR・CCR・DSCR {#metrics}

### IRR（内部収益率） {#irr}

年ごとのお金の出入りを並べ、その正味現在価値が0になる割引率を求めます。

```formula
0年目   : −初期自己資金
1〜N−1年目: その年の単年キャッシュフロー
N年目   : その年の単年キャッシュフロー + 売却手取り
```

−95%から+200%の範囲を二分法で100回絞り込みます。範囲内に答えがない場合（全期間赤字など）は「—」と表示します。サンプルのIRRは **5.16%** です。

税をオフにしていても、「譲渡税を考慮する」がオンなら売却手取りから譲渡税は引かれています。

### CCR（自己資金配当率） {#ccr}

```formula
CCR = 1年目の単年キャッシュフロー ÷ 初期自己資金
```

サンプルは72,978円÷2,736,000円＝ **2.67%** です。

### DSCR（返済余裕率） {#dscr}

```formula
NOI（営業純収益） = 1年目の収入 − 1年目の運営経費     ※ローン返済と税は含まない
DSCR             = NOI ÷ 1年目のローン返済額（元金＋利息）
```

サンプルは852,840円÷779,862円＝ **1.09** です。1.0を下回ると、家賃から経費を払った残りでローンを返しきれません。金融機関は1.2〜1.3以上を目安に見ることが多い指標です。

**注意してほしいのは、YOMUのDSCRは1年目の値だということです。** 1年目は金利上昇の前で、最初の退去もまだ起きていません。多くの物件で、保有期間中もっとも余裕のある年です。1年目のDSCRが1.2あっても、6年目や金利が上がった後に同じ余裕があるとは限りません。

## 10. 楽観シナリオは何を省いているか {#scenarios}

楽観シナリオは、業者の提案書やポータルサイトの簡易シミュレーションによくある前提を再現したものです。

| 項目 | 保守シナリオ | 楽観シナリオ |
|---|---|---|
| 金利 | 毎年上昇（上限まで） | 当初金利のまま |
| 家賃 | 毎年下落 | 当初家賃のまま |
| 入居 | 平均入居期間ごとに退去・空室 | 保有期間中ずっと満室 |
| 原状回復費・募集広告料 | 計上 | 計上しない |
| 礼金・更新料 | 計上 | 計上しない |
| 建物管理費・経常修繕費の上昇 | あり | なし |
| 設備交換・大規模修繕 | 計上 | 計上しない |
| 税 | 設定に従う | 計算しない |
| 管理委託料・固定資産税等・保険 | 計上 | 計上 |

```formula
シナリオ差額 = 楽観シナリオの累積キャッシュフロー − 保守シナリオの累積キャッシュフロー
```

サンプルでは、楽観 +2,554,229円 に対して保守 −5,395,484円、**差額は7,949,713円** です。1年目のキャッシュフローは両シナリオとも72,978円で同じで、差は2年目から開いていきます。提案書の1年目の数字が正しくても、それだけでは何も保証されないということです。

## 11. 信号機診断の判定ルール {#diagnosis}

判定は保守シナリオの結果に対して行います。まず、次の3つをすべて満たす物件を **「総合成績が良好」** とみなします。

- 総合損益がプラス
- IRRが5%以上
- 中度ストレス（当初金利+1pt・空室期間1.5倍・家賃下落率+0.5pt・修繕費上昇率+1pt）をかけても総合損益がプラス

### 赤（危険）— ひとつでも当てはまれば赤

| 条件 | 補足 |
|---|---|
| 1年目の毎月のキャッシュフローがマイナス | |
| 1年目のDSCRが1.1未満 | 総合成績が良好なら黄に留める |
| 自己資金が物件価格の10%未満 かつ 表面利回り5%未満 | 総合成績が良好なら対象外 |
| 総合損益がマイナス | |
| IRRがマイナス | |

### 黄（要注意）— 赤に当てはまらず、次のどれかに当てはまれば黄

| 条件 | 補足 |
|---|---|
| 1年目のDSCRが1.1以上1.3未満 | |
| 1年目のDSCRが1.1未満（総合成績が良好な場合） | |
| IRRが0%以上2%未満 | |
| 5年目までに単年で赤字になる | 1年目がプラスで、総合成績が良好でない場合 |
| 下の「楽観的な入力」が2つ以上 | 1つだけなら青のまま注意書きを出す |

**楽観的な入力として数えるもの**：空室期間1ヶ月未満 ／ 家賃下落率0.5%未満（上昇前提を含む）／ 管理委託料3%未満 ／ 原状回復費5万円未満 ／ 金利上昇ゼロ ／ 平均入居期間8年超 ／ 経常修繕費 年1万円未満

### 青（健全）

赤にも黄にも当てはまらない物件です。

### サンプル物件の判定

サンプルは **黄** です。1年目のDSCRが1.09で1.1を下回りますが、総合損益+1,735万円・IRR 5.16%・中度ストレスでも+972万円と総合成績が良好なので、赤ではなく黄に留まります。

裏を返すと、IRRが5%をわずかに下回るだけで、この物件は赤に変わります。しきい値の境目にある物件ほど、信号の色より理由文と数字そのものを見てください。

## 12. 感度分析・ストレステスト・最適売却年 {#analysis}

### 感度分析

次の8項目を1つずつ上下に振り、総合損益がどれだけ動くかを出して、動きの大きい順に並べます。

| 項目 | 振り幅 |
|---|---|
| 家賃 | ±10% |
| 家賃下落率 | ±0.5pt（下限0） |
| 当初金利 | ±0.5pt（下限0） |
| 金利上昇ペース | 2倍 ／ ゼロ |
| 空室期間 | ±1ヶ月（下限0） |
| 平均入居期間 | ±1年（下限0.5年） |
| 原状回復費 | ±50% |
| 売却時利回り | ±1pt（下限1%） |

### ストレステスト

| 名前 | 変える前提 | サンプルの総合損益 |
|---|---|---:|
| ベース | 現在の設定 | +1,735万円（IRR 5.16%） |
| 中度ストレス | 当初金利+1pt・空室期間1.5倍・家賃下落率+0.5pt・修繕費上昇率+1pt | +972万円（IRR 2.61%） |

### 最適売却年

3年目から保有期間の最後まで、各年に売却した場合の総合損益を計算し、金額が最大になる年を示します。IRRではなく総合損益の金額で比べています。サンプルの最適売却年は35年目です。

## 13. YOMUが計算していないこと {#limits}

計算を簡単にするために省いていることです。「影響」の欄は、実際より結果が良く出るか悪く出るかの向きを示します。

| 省いていること | 影響 |
|---|---|
| 変動金利の「5年ごと見直し」「1.25倍上限」（毎年、返済額を引き直す） | 金利上昇の途中年は厳しめ |
| 入居中の家賃は据え置き、という現実（毎年下げる） | 厳しめ |
| 退去時期のばらつき（毎回平均どおり） | どちらとも言えない |
| 固定資産税等・保険・設備交換・大規模修繕・原状回復費・募集広告料の物価上昇 | 甘め |
| 設備の実際の設置年（購入年から周期を数える） | どちらとも言えない |
| 税の支払い時期（実際は翌年に払う税を、その年に払う） | わずかに厳しめ |
| 所得の増減による税率の段階の変化（限界税率で一律） | どちらとも言えない |
| 設備交換・大規模修繕の資本的支出としての減価償却（全額をその年の経費にする） | その年は税が甘め、後の年は厳しめ |
| 土地を取得するための借入金の利子を損益通算できない制限 | 損益通算ありのとき甘め |
| 不動産所得の損失の繰越 | 損益通算なしのとき厳しめ |
| 所有期間5年以下の短期譲渡の税率（39.63%）。譲渡税は20.315%で一律 | 5年以内に譲渡益が出る売却では甘め |
| 購入諸費用を譲渡所得の取得費に含めること | 譲渡税が多めに出る＝厳しめ |
| 売却時の空室（利回り方式は満室時の家賃で売却価格を出す） | 甘め |

税の計算は判断の目安で、確定申告や個別の税務相談に代わるものではありません。

## 14. このページの30秒診断について {#widget}

[DSCRの節](#dscr)に置いた30秒診断は、アプリ本体の計算エンジンとは別の簡易版です。物件価格・家賃・自己資金の3つから **1年目の1ヶ月分だけ** を計算します。

```formula
家賃収入 = 家賃 × 96%（入居率）
経費     = 家賃収入 × 5% + 12,000円 + 115,000円 ÷ 12
毎月返済 = 金利1.8%・35年・元利均等
```

家賃下落・金利上昇・退去・設備交換・税・売却は入っていません。同じ入力でも、アプリのDSCRとは値が少し変わります。35年分の推移を見るには、アプリで計算してください。
